# VHS STATS — установка закрытой аналитики

Подготовленные компоненты:

- `Index.html` — интерфейс VHS STATS для iPhone (только после входа Google).
- `Dashboard.gs` — читает агрегированные события из Google Таблицы.
- `Collector.gs` — публичный *только для записи* приёмник без возможности прочитать чужие события.
- `../usage-stats.js` — клиент двух приложений, пока **отключён** (`COLLECTOR_URL = ''`).

**Важное ограничение:** без регистрации пользователей «уникальные люди» не считаются точно. Считается приблизительное количество устройств/хранилищ PWA, определяемых случайным 128-битным ID. Никаких фото, видео, имён файлов, содержимого работ, email, GPS или иных медиаданных приложение не отправляет.

## 1. Создать закрытую Google Таблицу

1. На [sheets.google.com](https://sheets.google.com) создать новую таблицу «VHS STATS DATA».
2. Права доступа таблицы оставить «Ограниченный доступ», никому не открывать.
3. Из адреса таблицы `https://docs.google.com/spreadsheets/d/ID_ЗДЕСЬ/edit` скопировать **только ID**.

## 2. Сборщик событий (отдельный Apps Script)

1. На [script.google.com](https://script.google.com) создать проект «VHS STATS COLLECTOR».
2. Заменить содержимое `Code.gs` на код из `Collector.gs`.
3. В `SPREADSHEET_ID` вставить ID приватной таблицы.
4. В «Развернуть → Новое развертывание → Веб-приложение» выбрать «Выполнять от имени: Я», «Кто имеет доступ: Все».
5. Подтвердить разрешение работать с этой таблицей. **Приложение-сборщик публично принимает события, но не предоставляет доступа на чтение.**
6. Скопировать URL проекта, который заканчивается на `/exec`.

Любой пользователь сети может отправлять поддельные события на публичный URL сборщика; это ограничение бесплатной схемы без собственного защищённого сервера. Для базовой некоммерческой аналитики схема подходит, но данные нельзя считать защищёнными от накрутки.

## 3. Закрытая панель (отдельный Apps Script)

1. Создать ВТОРОЙ проект «VHS STATS DASHBOARD» на [script.google.com](https://script.google.com).
2. Заменить `Code.gs` на `Dashboard.gs`, подставить тот же `SPREADSHEET_ID`.
3. Добавить HTML-файл с именем `Index` и вставить в него содержимое `Index.html`.
4. «Развернуть → Новое развертывание → Веб-приложение». «Выполнять от имени: Я», **«Кто имеет доступ: Только я»**.
5. Открыть ссылку панели в Safari из своего Google-аккаунта.
6. Проверить ту же ссылку в режиме без входа в Google. Она **не должна показывать статистику**. Если панель открывается без авторизации, прекратить публикацию и исправить настройки доступа.

**Нельзя публиковать панель Dashboard с настройкой «Все».** Иначе сведения могут стать доступны посторонним.

## 4. Активировать счётчик в приложениях

Сначала в установленном PHOTO VHS и VHS Video Lab на своём iPhone шесть раз нажать на маленькую надпись версии приложения: появится подтверждение «Устройство исключено из статистики VHS STATS». Делать отдельно в каждом установленном приложении; очистка данных/переустановка может снять исключение.

Затем в `usage-stats.js` заменить `COLLECTOR_URL = ''` на полученный **публичный URL сборщика** `https://script.google.com/macros/s/.../exec` (не на URL закрытой панели). Обновить версию сервиса и файлов в обоих PWA. Публичный URL приёмника **не является секретом**.

**До выполнения этих шагов сбор статистики выключен.**

## Устройство панели и метрики

- PHOTO VHS и VHS Video Lab отдельно, плюс общий итог.
- Периоды 24 часа, 7/30/90 дней; графики активности.
- Просмотры, приблизительно уникальные устройства, открытие камер, нажатия кнопок съёмки и экспорта.
- Нажатие «Экспорт» **не означает успешное сохранение**. Для учёта успешных сохранений понадобится отдельно подключить события завершения и протестировать их на iPhone.
- Установка приложения на домашний экран iPhone по ссылке без действий пользователя программно невозможна. Нужен пункт Safari «На экран Домой».

## Защита личных данных

Сборщик принимает только строго фиксированные названия событий, два допустимых имени приложений и случайный ID. Он не читает медиатеку, не записывает медиа, не смотрит выбранные файлы, не сохраняет названия файлов. При активации внизу приложения автоматически добавляется уведомление о технической статистике. Проверь требования к согласию пользователей в странах, где распространяются приложения.

Примечание: события передаются по HTTPS в режиме `fetch(..., mode:'no-cors')`; из-за ограничений Google Apps Script браузер не может подтвердить доставку. Отсутствие интернета, блокировщики и квоты Google могут приводить к потерям данных.
