# VHS Video Lab — личный аудиомост для музыки и Telegram

**Статус:** исходный код готов и протестирован в GitHub Actions. Worker **не разворачивается автоматически** вместе с GitHub Pages: для реальной онлайн-библиотеки требуется один раз разместить его в своём аккаунте Cloudflare и подключить собственного Telegram-бота.

## Что решает

- **Без загрузки музыки в «Файлы» iPhone:** получай треки из своей личной Telegram-библиотеки внутри VHS Video Lab, слушай, добавляй к видео, регулируй отдельно звук камеры и музыку, применяй VHS AUDIO и реакцию визуальных помех на биты.
- Отправляй или пересылай **аудиофайл** своему боту в Telegram. Worker получает через официальный Telegram Bot API метаданные и file_id. Сами MP3 **не записывает на Cloudflare KV**: запрашивает аудио у Telegram при выборе, передаёт его в оперативную память веб-редактора.
- Для разрешённых внешних аудиофайлов есть контролируемый HTTPS-аудиомост: клиент сначала пытается загрузить файл напрямую и лишь при ошибке сети/CORS/HTTP предлагает обращение к настроенному Worker.
- **Не решает:** защищённый DRM, запрет сервера HTTP 403, отсутствие прав на музыку или поиск произвольных песен на Hitmos. При HTTP 403 Worker возвращает отказ, а не имитирует успешный импорт.

## Однократная настройка (можно сделать через браузер)

**1. Создай Worker в своём Cloudflare.**

[Открыть мастер Deploy to Cloudflare для папки music-bridge](https://deploy.workers.cloudflare.com/?url=https://github.com/sh88dd-cmd/vhs-glitch-studio-mobile/tree/main/music-bridge)

Понадобится вход в Cloudflare/GitHub и подтверждение размещения проекта. Рабочий адрес будет похож на `https://vhs-video-music-bridge.<имя>.workers.dev`. Приложение на GitHub Pages продолжит работать отдельно.

**2. Проверь KV-хранилище.** В настройках Worker → **Bindings** должна быть KV namespace с именем переменной `TRACKS`. Мастер Cloudflare может создать её из `wrangler.toml`. Если не создал, открой Workers KV, создай namespace и привяжи к Worker как `TRACKS`. В KV хранятся только ID, названия и метаданные твоих файлов; записи автоматически истекают через 30 дней.

**3. Добавь секретный ключ Cloudflare.** В настройках Worker → **Variables and Secrets** добавь **Secret** с именем `BRIDGE_KEY` и случайным значением **не короче 20 символов** (желательно 32–48). Не публикуй его в GitHub и не отправляй в чат. Этот же ключ введёшь на iPhone.

**4. Создай своего Telegram-бота** через официальный [@BotFather](https://t.me/BotFather), команда `/newbot`. Бот даст токен. Узнай свой цифровой Telegram ID (например, через [@userinfobot](https://t.me/userinfobot)).

**5. Добавь ещё три секрета в Cloudflare Worker:**

- `TELEGRAM_BOT_TOKEN`: токен бота от BotFather.
- `TELEGRAM_USER_ID`: твой числовой Telegram ID. Сообщения других пользователей игнорируются.
- `TELEGRAM_WEBHOOK_SECRET`: ещё одна отдельная случайная строка из английских букв, цифр, `_` и `-`, например длиной 32 символа. Не путать с BRIDGE_KEY.

Все четыре значения должны находиться **в Cloudflare Secrets**, а не в исходниках. После сохранения при необходимости разверни Worker снова.

**6. Подключи мост на iPhone.** Открой [VHS Video Lab](https://sh88dd-cmd.github.io/vhs-glitch-studio-mobile/video/) → **♫ ТРЕКИ** → **Личная онлайн-библиотека — Telegram / аудиомост**. Вставь публичный HTTPS-адрес Worker и свой `BRIDGE_KEY`. Нажми **«Сохранить подключение»**, потом **«Проверить»**. Секретный ключ сохраняется только на время текущей сессии Safari/PWA; адрес хранится в локальном хранилище.

**7. Нажми «Подключить Telegram-бота».** Редактор сам зарегистрирует webhook через официальный Telegram Bot API, используя секреты внутри Worker. Тебе не нужно вставлять бот-токен в адресную строку телефона.

**8. Открой своего бота в Telegram, нажми «Start» и перешли боту аудиофайл (не просто ссылку на страницу песни).** В редакторе нажми **«Мои треки из Telegram»** → **Прослушать** / **Добавить**. Дальше используют обычный звуковой микшер, VHS AUDIO, «♫ БИТ» и экспорт.

## Безопасность и ограничения

- `BRIDGE_KEY` проверяется на каждом чтении аудио и списка треков. Запросы с посторонних веб-сайтов отвергаются по Origin. Telegram webhook дополнительно проверяет `X-Telegram-Bot-Api-Secret-Token` и `TELEGRAM_USER_ID`.
- Прокси имеет **список разрешённых HTTPS-доменов** `ALLOWED_AUDIO_HOSTS` (по умолчанию `upload.wikimedia.org,archive.org,*.archive.org`). Он не открывает произвольную сеть, запрещает перенаправления на неразрешённые домены, HTML-страницы вместо аудио, файлы больше 18 МБ.
- Если у тебя есть право использовать аудиофайлы с другого открытого домена, добавь домен в Cloudflare Worker → Variables `ALLOWED_AUDIO_HOSTS`, через запятую. Не добавляй сайты, блокирующие доступ или запрещающие такое использование; список доменов не обходит HTTP 403.
- Telegram Bot API ограничивает скачиваемые ботом файлы примерно 20 МБ; наш лимит ниже — **18 МБ**, чтобы защищать память iPhone. Декодированный звук ограничен в приложении отдельно.
- Песни не сохраняются в файлах телефона или KV Cloudflare, но **временно занимают оперативную память**, а Telegram хранит исходный присланный ему аудиофайл на своих серверах. Выгрузка, пауза и очистка памяти работают как прежде.
- **Авторское право:** добавляй лишь записи, на использование и включение в видео которых у тебя есть необходимые права/разрешение. Личный характер редактора не делает все сторонние музыкальные каталоги свободными для такого использования.
- В нашем GitHub **нет** секретов, токенов BotFather и пользовательских аудиофайлов. Не добавляй их туда при настройке.

## Диагностика

- **«Неверный секретный ключ» (401)** — Cloudflare `BRIDGE_KEY` не совпадает с ключом на iPhone.
- **«Telegram не настроен» (503)** — отсутствует KV `TRACKS` или одна из трёх настроек Telegram.
- **Нет треков** — перешли боту именно MP3/M4A/OGG как аудио/документ, а не веб-ссылку. Убедись, что `TELEGRAM_USER_ID` верный, и обнови список.
- **403 у внешнего источника** — тот сайт отказал серверу. Переход к личному мосту не устраняет этот отказ; используй разрешённую запись или отправь свою разрешённую копию через Telegram.
- **Аудио не декодируется** — проверь формат и размер; для iPhone лучше MP3/M4A до 18 МБ.
- **Проверка работает, но Telegram не включается** — открой Cloudflare Worker Logs; проверь Telegram BotFather токен, user ID, секрет вебхука и KV.

## Разработка и тестирование

```bash
cd music-bridge
node --test test-worker.mjs
npx wrangler deploy
```

Тесты на GitHub проверяют авторизацию, CORS, ограничение сайтов, реальный формат MP3 по сигнатуре, отказ 403, Telegram-webhook, список и получение аудио. Работа на твоём физическом iPhone и фактическая Cloudflare/Telegram интеграция **не подтверждены до развёртывания Worker в твоём аккаунте**.
