# Architecture review
This separate, read-only audit workflow captures all recorded street-frontage candidates from real in-game geometry with visibility metadata. It never deploys or marks a facade approved. The existing ledger's 244 entries are only an initial coverage inventory; visual review against actual sources and completion of the remaining area is required. The audit build injects test camera code only in the runner, not the live game. Captures are landscape to show complete facade context; iPhone graphics settings are retained. The workflow runs after a successful game build or manual dispatch.
