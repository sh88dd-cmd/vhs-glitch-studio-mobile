# VHS Video Lab 0.1.0 — экспериментальная видеоверсия

Первая отдельная видеоверсия VHS Glitch Studio Mobile находится в папке /video/ в том же репозитории. Фоторедактор по корневому адресу не изменён.

## Включено в первую сборку
- Загрузка локального видео и покадровый обработанный предпросмотр.
- 8 аналоговых VHS эффектов через браузерный JS-движок, изменения от кадра к кадру.
- Режимы SP, LP, EP; параметры интенсивности.
- Те же 23 встроенных FILM-профиля и точный алгоритм XMP из фото-версии.
- Чтение XMP из существующей базы photo app при доступности одного origin и storage context.
- Собственная видеобиблиотека; импорт ZIP с XMP, отдельных XMP и JSON backup фото-версии; фото-база не мутируется.
- REC, PLAY, батарея, дата; VHS воздействует на них тоже.
- Экспериментальный экспорт первых 30 секунд через canvas.captureStream + MediaRecorder, аудио через Web Audio где возможно.
- Свой service worker, отдельный офлайн-кэш. Файлы не отправляются на сервер.

## Ограничения
- Это пока НЕ оригинальная Rust/WASM-сборка ntsc-rs. Текущий движок самостоятельный: ../ntsc-photo.js.
- Исходный проект ntsc-rs-web распространяется по GPL-3.0-or-later; исходники этого веб-приложения здесь не копировались.
- Ядро ntsc-rs с permissive лицензиями предполагается интегрировать через отдельную сборку WASM.
- Safari/iPhone может не поддержать некоторые HEVC/HDR видео; MediaRecorder экспорт и звук пока не проверены на реальном iPhone.
- Превью невысокого разрешения; экспорт в реальном времени и максимум первых 30 сек.
- Нужен WebCodecs + muxer (например Mediabunny) для более надёжного полного MP4/AAC экспорта.
- Отдельные установленные PWA могут иметь изолированные storage contexts, поэтому предусмотрен импорт ZIP и JSON backup.
- Не удаляй существующую фото-PWA и не очищай IndexedDB / Safari данные: там могут быть сохранённые XMP.
