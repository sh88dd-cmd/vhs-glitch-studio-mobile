VHS GLITCH STUDIO MOBILE v1.0 — ИНСТРУКЦИЯ ДЛЯ IPHONE
==================================================

Это PWA: отдельная иконка на экране iPhone, без App Store,
без подписки Apple Developer, без Mac, iTunes и USB-кабеля.
Публикация файлов необходима ОДИН раз: для этого подойдёт
бесплатный GitHub Pages (публичный репозиторий).

СТАТУС ЭТОЙ ВЕРСИИ
------------------
Файлы приложения созданы. Базовый интерфейс и обработка проверены в Chromium.
На реальном iPhone 16 Pro установка и офлайн-работа ещё не проверены.
Публичная ссылка не создана — для неё нужно разместить файлы в аккаунте GitHub.

КАК ОТКРЫТЬ НА WINDOWS ДЛЯ ПРЕДПРОСМОТРА
--------------------------------------
1. Распакуй ZIP с проектом.
2. Открой папку VHS_Glitch_Studio_iPhone_PWA.
3. Дважды нажми START_PREVIEW_WINDOWS.bat.
4. Откроется браузер с адресом http://localhost:8765.
5. Это локальная проверка на компьютере; на телефон по этой ссылке
   приложение не установится.

КАК БЕСПЛАТНО ПОСТАВИТЬ НА IPHONE (ОДИН РАЗ)
-------------------------------------------
1. На компьютере зайди на https://github.com/ и войди или создай
   бесплатный аккаунт.
2. Нажми «New repository» (создать репозиторий).
   Назови, например, vhs-glitch-studio-mobile.
   Выбери Public (это нужно для бесплатного GitHub Pages).
3. Добавь в корень репозитория содержимое папки приложения:
   index.html, app.js, styles.css, looks.json, jszip.min.js,
   sw.js, manifest.webmanifest, .nojekyll и папку icons.
   В интерфейсе GitHub: Add file → Upload files → Commit changes.
   Важно: загрузить СОДЕРЖИМОЕ папки, а не сам ZIP.
4. В репозитории открой Settings → Pages.
   В «Build and deployment» выбери Deploy from a branch.
   Branch: main; Folder: /(root); нажми Save.
5. После публикации GitHub покажет адрес вроде
   https://ИМЯ.github.io/vhs-glitch-studio-mobile/
   Это пример, а не готовая ссылка.
6. Открой адрес на iPhone в Safari (не во встроенном браузере мессенджера).
7. Поделиться → На экран Домой → Добавить.
8. Открой иконку VHS Studio на главном экране.
9. Дождись статуса «ГОТОВО ОФЛАЙН».
10. Включи Авиарежим и проверь запуск приложения и обработку фотографии.
    При необходимости верни интернет, открой/обнови страницу и повтори тест.

КОНФИДЕНЦИАЛЬНОСТЬ
------------------
На GitHub публикуется только исходный код и встроенные 23 авторских
плёночных стиля. Личные фотографии НЕ загружаются в GitHub.
Обработка происходит локально внутри браузера на устройстве.
Репозиторий с кодом будет публичным, но твои фотографии не публикуются.

451 ПРЕСЕТ EMULSIONPRESETS
-------------------------
В архиве приложения уже встроено 23 авторских стиля.
451 профиль Lightroom из чужой открытой библиотеки НЕ зашит в ZIP.
Эти профили можно добавить один раз:
1. На iPhone с интернетом открой официальный выпуск:
   https://github.com/peva3/EmulsionPresets/releases/tag/v3.1.4
2. Скачай файл lr-presets-all.xmp.zip, сохрани в приложение «Файлы».
3. Открой VHS Studio → FILM → Дополнительные профили.
4. Нажми «Импортировать архив XMP ZIP», выбери скачанный ZIP.
5. Программа импортирует поддерживаемые XMP в память устройства.
6. После импорта интернет для использования этих профилей не нужен.
7. СРАЗУ скачай резервную копию из вкладки «Настройки» и сохрани её
   в «Файлы» или на другом устройстве.

ВНИМАНИЕ: XMP профили лишь приблизительно интерпретируются нашим
JavaScript-движком, потому что на iPhone нет Adobe Camera Raw.
Это не гарантия совпадения с результатом Lightroom.
Ранее использовавшиеся коммерческие RNI профили сюда не включены.

РЕЗЕРВНАЯ КОПИЯ
--------------
• Данный ZIP является копией исходников программы.
• Внутри работающего приложения нажми «Резервная копия · Настройки».
• Нажми «Скачать резервную копию настроек и плёнок».
• Сохрани VHS_Studio_BACKUP_дата.json в «Файлы» на iPhone и желательно
  скопируй на Windows/другой накопитель.
• Для восстановления нажми «Восстановить из резервной копии»
  и выбери сохранённый JSON.
• Этот файл НЕ содержит личные фотографии и НЕ является установщиком.

ЕСЛИ IPHONE ОЧИСТИЛ ДАННЫЕ
-------------------------
При рабочем адресе GitHub Pages снова открой приложение с интернетом;
файлы повторно загрузятся, компьютер не нужен.
После этого восстанови настройки и импортированные XMP из JSON-бэкапа.
Если адрес GitHub Pages больше не доступен, используй копию исходников
ZIP и заново опубликуй их на бесплатном хостинге.
Офлайн-кэш может быть удалён системой; абсолютную сохранность PWA iOS
не гарантирует.

ВОЗМОЖНОСТИ
-----------
• VHS: шипящие полосы, волны, сдвиги строк, RGB, зерно,
  цветные VHS-волны, отдельные тонкие цветные штрихи.
• FILM: 23 авторских стиля; 451 XMP после отдельного импорта;
  импорт .cube LUT размером до 33³; зерно, halation, засветки,
  пыль, виньетка; белая рамка 30%; подпись снизу.
• Включай только VHS, только FILM или оба одновременно.
• КАМЕРА: REC, PLAY, дата/время, батарея, положение и размер по отдельности.
• Batch до 50 фото: по 6 превью на странице, увеличение отдельного кадра.
• Batch экспорт в ZIP, одиночный экспорт JPEG/PNG.
• Все эффекты на основе пикселей: лица и окружение не генерируются.

ОГРАНИЧЕНИЯ
-----------
• PWA НЕ нативное iOS приложение .ipa.
• Не гарантирована одинаковая точность и скорость по сравнению с Windows.
• 50 фото в полном размере могут превысить оперативную память iPhone.
  Используй Batch «Оптимальный — до 2000 px» или небольшие серии.
• Большие исходники и белая рамка увеличивают размер холста.
• Чтобы восстановить после полной очистки кэша, потребуется интернет.
• На iPhone реальная работа ещё требует тестирования.
